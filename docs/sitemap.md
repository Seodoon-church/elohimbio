# 사이트맵 — 엘로힘바이오 (elohimbio.com)

## 전체 URL 구조

```
elohimbio.com/
└── [locale]/                    ← ko | en | zh-CN | zh-TW | ja | vi | th | id | ar | hi
    ├── (홈)                     → /[locale]
    ├── about/                   → 회사소개
    ├── technology/              → 핵심기술
    ├── products/                → 제품
    │   ├── sinsaengssam/        → 신생삼 상세
    │   ├── doraji/              → 신생 도라지 상세
    │   └── garlic/              → 신생 마늘 상세
    ├── business/                → 사업소개
    ├── ir/                      → 투자자 IR (로그인 필요)
    │   └── login/               → IR 로그인
    ├── contact/                 → 문의하기
    └── news/                    → 뉴스·공지 (Phase 2)
        └── [slug]/              → 뉴스 상세
```

### 🏠 홈 (/)

**타깃**: 소비자 + 투자자 동시
**핵심 목표**: 두 타깃을 각자의 여정으로 분기

| 섹션 | 컴포넌트 | 설명 |
|------|----------|------|
| Hero | `HeroSection` | 풀스크린 신생삼 비주얼 + 슬로건 + 2개 CTA |
| 핵심 수치 | `StatsSection` | 30년 기술 / F2 800배 / 홍게 4,500톤 |
| 3대 사업 | `BusinessPillars` | 스마트팜 / 비료공장 / 치유센터 카드 |
| 기술 미리보기 | `TechPreview` | 인큐베이터 농법 한 줄 + 더보기 링크 |
| 제품 하이라이트 | `ProductHighlight` | 3종 제품 카드 (신생삼·도라지·마늘) |
| CTA | `CTASection` | 문의하기 / 체험 신청 유도 배너 |

**CTA 분기**:

- 투자자 → `/ir`

**타깃**: 소비자 + 투자자
**핵심 목표**: 신뢰 구축, 30년 기술력 증명

| 섹션 | 내용 |
|------|------|

| 연혁 타임라인 | 1989년 비료 개발 → 2018년 유기농 신생삼 완성 → 현재 |
| 대표 소개 | 이춘길 대표, 30년+ 농업 기술 개발 이력 |
| 파트너 | 엘로힘팜, 하우인터내셔널 |
| 오시는 길 | 지도 + 주소 |

**연혁 주요 이정표**:

- 2004 — 인큐오이·인큐애호박 특수비닐 개발
- 2006 — 천연 Bio 공장 설립
- 2010 — 갈변 억제 인삼·마늘·감자 개발
- 2012 — 천연 Bio 개발, 높은 진세노사이드 확보
- 2014 — 울라이트 딸기·토마토 인큐농법 개발
- 2018 — 유기농 기능성 신생삼 묘삼 연구개발 완료
- 2023 — 생삼에서 높은 진세노사이드 F2 개발 성공

### 🔐 투자자 IR (/ir)

**접근**: Firebase Auth 로그인 필수
**타깃**: 투자자 전용

#### IR 로그인 (/ir/login)
- 이메일/비밀번호 입력
- 로그인 실패 시 "담당자에게 계정 문의" 안내
- 비회원 가입 불가 (관리자가 직접 계정 발급)

#### IR 대시보드 (/ir) — 로그인 후
| 섹션 | 내용 |
|------|------|
| 사업 요약 | 핵심 지표 카드 |
| 투자 구조 | 1차 265억 / 2차 750억 / 총 1,000억 |
| 매출 계획 | 스마트팜 1,200억 / 비료 1,500억 / 제약 1,000억 / 치유센터 300억 |
| 자료실 | IR 문서 PDF 다운로드 (Firebase Storage) |
| 담당자 | 연락처 직접 표시 |

### 📬 문의하기 (/contact)

**타깃**: 소비자 + 투자자 + 파트너
**핵심 목표**: 리드 수집, Firestore 저장

**폼 필드**:
```
문의 유형 (선택 필수):
  ○ 소비자 제품 문의
  ○ 투자자 문의
  ○ 파트너십·B2B 문의
  ○ 체험 농장 예약
  ○ 기타

이름 *
이메일 *
연락처 *
소속/회사 (선택)
메시지 *
개인정보 수집 동의 *
```

**제출 후 처리**:
1. Firestore `contacts` 컬렉션에 저장
2. Firebase Functions → 관리자 이메일로 알림 발송
3. 사용자에게 접수 완료 화면 표시
